# Визуальные истории

Портфолио видеоработ, fashion-визуалов и карточек для маркетплейсов.

Контакты: [Telegram @olyakutsenko](https://t.me/olyakutsenko), [+7 915 239-79-45](tel:+79152397945).

Статический сайт для GitHub Pages. Публикация из ветки `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Сборка, база данных и аккаунт ChatGPT посетителям не нужны. Все фотографии, видео, шрифты и библиотека проигрывателя размещены в `assets/`.

Разделы: главная, `fashion/` (10 образов), `marketplace/` (3 карточки).

VELMORA воспроизводится из MP4 с H.264/AAC и метаданными в начале файла (`faststart`): 1080 × 1920, 60 кадров/с на больших экранах; 720 × 1280, 30 кадров/с на экранах до 850 px и при включённой экономии трафика. Ограничение видеопотока — 4 Мбит/с и 1,6 Мбит/с соответственно. Исходная версия VELMORA сохранена в `assets/velmora/` и доступна по ссылке «Открыть исходник» в Dropbox.

Остальные медиа перенесены без перекодирования и дополнительного сжатия. «Спорт» использует HLS с исходным HEVC; воспроизведение зависит от поддержки HEVC устройством. «Арена Мяча» использует HLS с исходным H.264 в разрешении 2160 × 3840 (4K). Остальные видеоработы, включая «Для вашей пиццерии 👌🏻», размещены как MP4. Ссылки на исходники отдельных работ могут открывать Dropbox или Google Drive.

При изменении адреса публикации нужно обновить `canonical`, `og:url` и `og:image` в трёх HTML-страницах. Внутренние ссылки и ресурсы используют относительные пути.

Лицензии шрифтов и библиотеки воспроизведения находятся в `assets/`.
