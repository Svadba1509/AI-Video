# Визуальные истории

Портфолио видеоработ, fashion-визуалов и карточек для маркетплейсов.

Контакты: [Telegram @olyakutsenko](https://t.me/olyakutsenko), [+7 915 239-79-45](tel:+79152397945).

Статический сайт для GitHub Pages. Публикация из ветки `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Сборка, база данных и аккаунт ChatGPT посетителям не нужны. Все фотографии, видео, шрифты и библиотека проигрывателя размещены в `assets/`.

Разделы: главная, `fashion/` (10 образов), `marketplace/` (3 карточки).

Медиа перенесены без перекодирования и дополнительного сжатия. VELMORA использует HLS с исходным HEVC; воспроизведение зависит от поддержки HEVC устройством. Другие видеоработы размещены как MP4. Ссылки на исходники отдельных работ могут открывать Dropbox или Google Drive.

При изменении адреса публикации нужно обновить `canonical`, `og:url` и `og:image` в трёх HTML-страницах. Внутренние ссылки и ресурсы используют относительные пути.

Лицензии шрифтов и библиотеки воспроизведения находятся в `assets/`.
